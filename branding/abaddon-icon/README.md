## Manual uploads (API limited)

### X — @ChainLordsHQ
1. x.com → Profile → **Edit profile** → photo  
2. Upload `X-avatar-400.png`  
3. Optional header: full poster or site wallpaper  

### Discord — server
1. Server Settings → **Overview** → Image  
2. Upload `Discord-server-512.png` (or `discord-server-icon.png`)  

### Discord — bot
1. [Discord Developer Portal](https://discord.com/developers/applications) → Chain Lords Bot → **App Icon** / Bot icon  
2. Same face file (256+)  

### Landing / play
Icons are under `landing/` and `mp-client/public/` — redeploy Railway + play client when ready.
