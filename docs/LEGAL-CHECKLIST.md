# Legal / compliance checklist (operational)

> **Not legal advice.** Short launch checklist for Chain Lord / this repo.  
> Deep IP research: [`LEGAL-IP-RESEARCH.md`](./LEGAL-IP-RESEARCH.md).  
> Confirm each item with counsel before public launch, paid features, or NFT minting.

## IP & branding

- [ ] Prefer commercial brand **Chain Lord(s)** (or other cleared mark); avoid marketing as “Helbreath” until counsel clears.
- [ ] Do **not** assume bankruptcy / private-server culture / USPTO empty search = free to clone assets.
- [ ] Replace or license: logos, classic client art, maps, UI chrome, city names (Aresden/Elvine), signature item names.
- [ ] No shipping of leaked Siementech C++ trees; treat Olympia custom IP separately from original Helbreath IP.
- [ ] Trademark clearance (USPTO / KIPO / EUIPO / INPI AR + similar marks) — see research doc.
- [ ] File own marks for product brand in target territories.

## Terms of service / players

- [ ] ToS + EULA covering account, virtual items, NFTs, bans, arbitration/venue.
- [ ] Clarify ownership of user-generated content and guild names.
- [ ] Refund / chargeback / wallet-error policy (crypto is irreversible).
- [ ] Prohibited conduct (bots, RMT off-platform if banned, harassment).

## Privacy & data

- [ ] Privacy policy (wallet addresses, Discord IDs, IP logs, chat, KYC if any).
- [ ] Cookie / analytics disclosure if landing + client collect data.
- [ ] Argentina / LatAm / GDPR-style obligations if users are EU-based.
- [ ] Data retention + deletion requests process.

## Crypto / NFTs / economy

- [ ] Securities / commodity framing of gov token or tournament credits — counsel review.
- [ ] NFT terms: what the token represents (license vs ownership of IP), secondary market risks.
- [ ] AML / sanctions screening if fiat on-ramps or custodial prizes.
- [ ] Tax reporting posture for prizes and marketplace fees.
- [ ] Clear disclosure that blockchain txs are public and irreversible.

## Tournaments / prizes / gambling adjacency

- [ ] Spectator **betting** is out of product scope — keep it that way unless counsel + licenses.
- [ ] Participant prize pools / escrow: gambling & skill-game analysis per territory.
- [ ] Age gates; geo-block if required.
- [ ] Anti-match-fixing / collusion rules in ToS.

## Minors & safety

- [ ] Age minimum (e.g. 18+ for wallet/NFT features) and parental consent where required.
- [ ] Chat moderation / reporting pipeline.
- [ ] No marketing aimed at children if product is adult-gated.

## Ops

- [ ] DMCA / notice-and-takedown contact.
- [ ] Security disclosure / bug bounty channel.
- [ ] Insurance / corporate entity that holds licenses and marks.
